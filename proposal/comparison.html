    Security proposal for management · option comparison · General edition

    Proposal 2 vs Proposal 3

    Proposal 2, AWS edge: Amazon CloudFront with AWS WAF at the edge in front of the origin load balancer. Proposal 3, existing edge: the Imperva Cloud WAF site stays as the first filter, with AWS WAF at the origin. Both keep the same administrator path: AWS Verified Access, IAM Identity Center with mandatory MFA, an administrator web ACL and CloudShell for break-glass.

    Basis: the management proposal items p2-* and p3-*, the strategy deep dives 8.1 and 8.7, the budget worksheet defaults (10 million public requests a month, 730 hours, up to 100 administrators), us-east-1 data transfer prices, and official AWS and Imperva documentation re-checked on 29 October 2026. Amounts are USD list prices or the worksheet’s planning placeholders, never vendor quotes.

    02 · WHAT THE COMPARISON SHOWS

    Five things the totals alone do not say

    Cost

    With failover priced in, the two options cost the same

    The worksheet used to start Proposal 2 at the USD 200 Business plan, but that plan has no origin failover and the edge-served emergency page needs one. It now starts at Premium (USD 1,000) plus the origin web ACL, so Proposal 2 lands at USD 3,575.70, USD 3.65 below Proposal 3. The decision turns on the Imperva quote, not on the AWS lines.

    Omissions

    Each option was missing a small AWS line, now priced

    Proposal 2 describes an origin web ACL in BLOCK as a second layer, but the worksheet priced only the CloudFront package: about USD 21 a month at 10 million origin-bound requests. Proposal 3 makes ALB mutual TLS mandatory, and a trust store costs USD 0.005 an hour, about USD 3.65 a month. Both lines are in the worksheet since 29 October 2026.

    Traffic

    Proposal 3 keeps paying AWS for every byte sent to Imperva

    The ALB answers Imperva over the internet, so us-east-1 bills data transfer out at USD 0.09 per GB for the first 10 TB. CloudFront origin fetches are free and the flat-rate plan covers delivery with no overage. This is an existing cost that Proposal 2 removes and the worksheet leaves out of both options.

    Contract

    Two Imperva features the design relies on are subscription-dependent

    Imperva's documentation says both site failover and log integration depend on the subscription. The S3 emergency-page failover (CH-12) and the home-Region log push (B22) only exist in Proposal 3 if the contract includes them. The written scope confirmation that p3-cost asks for must name both.

    Admin

    The administrator path is identical, so it does not decide anything

    Both options spend USD 504.70 a month on Verified Access and the administrator web ACL, and both keep the console off the public edge. The only difference is which edge the admin plane bypasses. Public and admin planes differ sharply inside each option, which section 06 shows.

    09 · BEFORE APPROVAL

    What each option must prove, and what the quote must say

    Proposal 2

    Approve only after

    A traffic model with normal and emergency forecasts; an origin-bypass test proving a direct connection to the ALB is refused (G6); a cache-update test against the publishing procedure; the surge drill with edge failover and an emergency guidance update (G11); a residency review accepting worldwide edge delivery; and a decision between Premium and pay-as-you-go once the failover requirement is priced.

    Proposal 3

    Approve only after

    A written Imperva price and scope confirmation naming the tier, bot management, the DDoS SLA, site failover, log integration to S3, traffic allowances and overage terms; mandatory origin mutual TLS tested (G6); the log push to the home Region confirmed before go-live (B22); the DPA and residency clauses in the supplier register; and the comparison of that total plus the avoided migration against Proposal 2.

    Both

    Unchanged either way

    Verified Access with Identity Center MFA for administrators, the origin web ACL in BLOCK after a clean seven-day COUNT period, exact-match public routes, the signed S3 emergency page, Kyverno in Enforce, and the twelve go-live gates with evidence.

    If the Imperva quote lands near the USD 1,000 placeholder, the two options cost the same on the AWS lines and the choice is about operations and contract value: one vendor with no overage and no migration risk on AWS egress, against an existing edge with a contractual DDoS SLA and no migration. If the quote is materially higher, Proposal 2 on Premium is cheaper and also removes the metered egress. If it is materially lower, Proposal 3 wins on price but still needs failover and log push in the contract.
